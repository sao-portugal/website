# São — website

Static brand site for São hard seltzer, hosted on GitHub Pages.

- `index.html` — page structure
- `styles.css` — colours, type and layout
- `main.js` — 18+ age check and EN/PT language switch (all copy for both languages lives here)
- `assets/` — logo (SVG) and favicon

To show the "Email us" button, set `CONTACT_EMAIL` at the top of `main.js`.
